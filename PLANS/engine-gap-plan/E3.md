## Step E3.1 — Engine: wire user_prompt config into applyPrompt()

**What:** `applyPrompt()` currently leaves `in.userDescription` and
`in.avoidPhrases` empty, even though `_cfg.user_prompt` holds the user's
values (after E0). Fix this by populating all `PromptInputs` fields from
`_cfg`.

Additionally, map `voice_strength` (0–100) to a limit on the number of
exemplars passed into `buildSystemPrompt`. At 0, no exemplars; at 100,
all exemplars; at 50 (default), the existing `profile->exemplars()` list
(up to budget).

**File:** `fcitx5-engine/src/xtype.cpp`

Find `applyPrompt()` and update:

```cpp
void XTypeEngine::applyPrompt() {
    PromptInputs in;
    in.base            = std::string(InferenceClient::base_system_prompt());
    in.profile         = _profile.get();
    in.includeExamples = _cfg.learning.include_examples_in_prompt;
    in.budgetChars     = kPromptBudget;

    // Populate user voice fields from config (wired after E0).
    in.userDescription = _cfg.user_prompt.description;
    in.avoidPhrases    = _cfg.user_prompt.avoid_phrases;

    // voice_strength (0–100) limits exemplar count proportionally.
    // At 0: no exemplars regardless of profile. At 100: full list.
    // At 50 (default): unchanged behaviour (all exemplars up to budget).
    if (_profile && !_profile->exemplars().empty() &&
        _cfg.learning.voice_strength < 100) {
        size_t maxEx = (_cfg.learning.voice_strength == 0)
            ? 0
            : static_cast<size_t>(
                std::ceil(_profile->exemplars().size() *
                          (_cfg.learning.voice_strength / 100.0)));
        // Pass a trimmed profile view if needed.
        // buildSystemPrompt takes PromptInputs::profile; we can't trim the
        // profile directly. Instead, set includeExamples=false when maxEx==0,
        // or temporarily limit via a wrapper approach.
        // Simplest: if voice_strength == 0, disable examples entirely.
        if (maxEx == 0)
            in.includeExamples = false;
        // For partial strength, buildSystemPrompt drops longest exemplars
        // when over budget — that is a proxy but not exact. For V1, 0 vs
        // non-zero is sufficient. Full proportional control is Session E4.
    }

    // Tone: append a short modifier to the base prompt if set.
    if (!_cfg.user_prompt.tone.empty() && _cfg.user_prompt.tone != "default") {
        // Append tone instruction after the base (within budget).
        // tone values: "technical", "casual", "professional", "concise"
        static const std::unordered_map<std::string, const char*> toneMap = {
            {"technical",     " Prefer precise technical terminology."},
            {"casual",        " Use a relaxed, conversational tone."},
            {"professional",  " Use formal, professional language."},
            {"concise",       " Be brief and direct."},
        };
        auto it = toneMap.find(_cfg.user_prompt.tone);
        if (it != toneMap.end())
            in.base += it->second;
    }

    bool truncated = false;
    auto prompt = buildSystemPrompt(in, &truncated);
    if (truncated)
        log_warn("system prompt truncated to fit 2000-char budget");
    size_t exCount = _profile ? _profile->exemplars().size() : (size_t)0;
    dbg("[prompt] set %zu chars exemplars=%zu desc_len=%zu avoid=%zu truncated=%d",
        prompt.size(), exCount,
        in.userDescription.size(),
        in.avoidPhrases.size(),
        truncated ? 1 : 0);
    _inference.set_system_prompt(std::move(prompt));
}
```

Add `#include <unordered_map>` and `#include <cmath>` to `xtype.cpp`
if not already present.

**Unit tests for applyPrompt / buildSystemPrompt integration:**

Add to `fcitx5-engine/tests/test_prompt_builder.cpp` (create if absent):

```cpp
#include <catch2/catch_test_macros.hpp>
#include "prompt_builder.h"
#include "style_profile.h"

TEST_CASE("user description appears in prompt") {
    PromptInputs in;
    in.base = "Base prompt.";
    in.userDescription = "A software engineer.";
    in.budgetChars = 2000;
    auto p = buildSystemPrompt(in);
    REQUIRE(p.find("A software engineer.") != std::string::npos);
}

TEST_CASE("avoid phrases appear in prompt") {
    PromptInputs in;
    in.base = "Base.";
    in.avoidPhrases = {"synergy", "leverage"};
    in.budgetChars = 2000;
    auto p = buildSystemPrompt(in);
    REQUIRE(p.find("synergy") != std::string::npos);
    REQUIRE(p.find("leverage") != std::string::npos);
}

TEST_CASE("prompt respects budget") {
    PromptInputs in;
    in.base = std::string(1800, 'x');
    in.userDescription = std::string(300, 'y');
    in.budgetChars = 2000;
    bool truncated = false;
    auto p = buildSystemPrompt(in, &truncated);
    REQUIRE(p.size() <= 2000);
    REQUIRE(truncated);
}

Add the following Q_PROPERTYs (only if missing):

Q_PROPERTY(QString     userTone         READ userTone         WRITE setUserTone         NOTIFY userToneChanged)
Q_PROPERTY(QStringList userAvoidPhrases READ userAvoidPhrases WRITE setUserAvoidPhrases NOTIFY userAvoidPhrasesChanged)
```

**File:** `settings/qt6-app/src/config_store.cpp`

In `load()`, read from `[user_prompt]` (if not already present — the
settings app may already write these keys):

```cpp
if (tbl.contains("user_prompt")) {
    auto& up = *tbl["user_prompt"].as_table();
    if (auto v = up["description"].value<std::string>())
        _userDescription = QString::fromStdString(*v);
    if (auto v = up["tone"].value<std::string>())
        _userTone = QString::fromStdString(*v);
    if (auto* arr = up["avoid_phrases"].as_array()) {
        _userAvoidPhrases.clear();
        for (auto& el : *arr)
            if (auto s = el.value<std::string>())
                _userAvoidPhrases.append(QString::fromStdString(*s));
    }
}
```

In `save()`, write under `[user_prompt]`:

```cpp
auto& up = tbl.insert_or_assign("user_prompt", toml::table{}).first->second;
// Write only non-empty values (omit empty description/tone/phrases).
if (!_userDescription.isEmpty())
    up.as_table()->insert_or_assign("description", _userDescription.toStdString());
if (!_userTone.isEmpty() && _userTone != "default")
    up.as_table()->insert_or_assign("tone", _userTone.toStdString());
if (!_userAvoidPhrases.isEmpty()) {
    toml::array arr;
    for (const auto& s : _userAvoidPhrases)
        arr.push_back(s.toStdString());
    up.as_table()->insert_or_assign("avoid_phrases", std::move(arr));
}
```

### Step E3.2b — PagePersonalisation QML changes

**File:** `settings/qt6-app/qml/pages/PagePersonalisation.qml`

After the existing `XSection` for "Your voice profile" (the exemplars
card), add a new `XSection` labelled `03` "Your voice settings":

```qml
XSection {
    num: "03"
    title: "Your voice"
    description: "Personalise suggestions to match how you write"
}

// Description field
XRow {
    label: "About you"
    desc: "One sentence about your writing context. Included in the AI prompt."
    XInput {
        width: 280
        placeholderText: "e.g. Senior engineer who writes tersely"
        text: Config.userDescription
        onEditingFinished: Config.userDescription = text
    }
}

// Tone selector
XRow {
    label: "Tone"
    desc: "Adjusts the style modifier added to the AI prompt."
    XSegmented {
        model: ["Default", "Casual", "Professional", "Technical", "Concise"]
        currentIndex: {
            var t = Config.userTone
            if (t === "casual")       return 1
            if (t === "professional") return 2
            if (t === "technical")    return 3
            if (t === "concise")      return 4
            return 0  // "default"
        }
        onSelected: function(i) {
            var tones = ["", "casual", "professional", "technical", "concise"]
            Config.userTone = tones[i]
        }
    }
}

// Avoid phrases (same UX as BlockList section 02)
XSection {
    num: "04"
    title: "Phrases to avoid"
    description: "AI will avoid generating these in suggestions (different from Blocklist which prevents all suggestions)"
}

XRow {
    XInput {
        id: avoidInput
        placeholderText: "Add phrase…"
        width: 220
    }
    XButton {
        label: "Add"
        onClicked: {
            var p = avoidInput.text.trim()
            if (p.length > 0) {
                Config.userAvoidPhrases = Config.userAvoidPhrases.concat([p])
                avoidInput.text = ""
            }
        }
    }
}

Repeater {
    model: Config.userAvoidPhrases
    XPhraseRow {
        phrase: modelData
        onRemove: {
            var list = Config.userAvoidPhrases.filter(function(x) { return x !== modelData })
            Config.userAvoidPhrases = list
        }
    }
}
```

**Style notes:**
- `XInput` with `onEditingFinished` fires on Enter or focus-out — correct
  for a text field (not a slider debounce).
- `userAvoidPhrases` is a `QStringList`; QML assignment of `concat()`
  triggers the NOTIFY signal and the debounced save.
- The avoid-phrases list uses the same XPhraseRow primitive as BlockList.
