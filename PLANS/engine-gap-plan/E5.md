## Step E5.1 — ConfigStore additions

**File:** `settings/qt6-app/src/config_store.h`

Before adding anything, verify which properties and TOML wiring are already present:

```bash
grep -n "temperature\|topP\|stopTokens\|maxCorpusMb\|minSentenceChars\|includeExamplesInPrompt" \
    settings/qt6-app/src/config_store.h settings/qt6-app/src/config_store.cpp
```

For each property that appears in **both** files (Q_PROPERTY in `.h`, and
load/save in `.cpp`), skip it entirely. Only add what is genuinely absent.

```cpp
// Inference — advanced
Q_PROPERTY(double      temperature          READ temperature          WRITE setTemperature          NOTIFY temperatureChanged)
Q_PROPERTY(double      topP                 READ topP                 WRITE setTopP                 NOTIFY topPChanged)
Q_PROPERTY(QStringList stopTokens           READ stopTokens           WRITE setStopTokens           NOTIFY stopTokensChanged)

// Learning — corpus settings
Q_PROPERTY(int         maxCorpusMb          READ maxCorpusMb          WRITE setMaxCorpusMb          NOTIFY maxCorpusMbChanged)
Q_PROPERTY(int         minSentenceChars     READ minSentenceChars     WRITE setMinSentenceChars     NOTIFY minSentenceCharsChanged)
Q_PROPERTY(bool        includeExamplesInPrompt READ includeExamplesInPrompt WRITE setIncludeExamplesInPrompt NOTIFY includeExamplesInPromptChanged)
```

Defaults:
- `temperature`: 0.3
- `topP`: 0.9
- `stopTokens`: `[".", "!", "?", "\n"]`
- `maxCorpusMb`: 50
- `minSentenceChars`: 12
- `includeExamplesInPrompt`: true

**File:** `settings/qt6-app/src/config_store.cpp`

In `load()`, read from `[inference]`:

```cpp
if (auto v = tbl["inference"]["temperature"].value<double>())  _temperature = *v;
if (auto v = tbl["inference"]["top_p"].value<double>())        _topP = *v;
if (auto* arr = tbl["inference"]["stop_tokens"].as_array()) {
    _stopTokens.clear();
    for (auto& el : *arr)
        if (auto s = el.value<std::string>())
            _stopTokens.append(QString::fromStdString(*s));
}
```

In `load()`, read from `[learning]`:

```cpp
if (auto v = tbl["learning"]["max_corpus_mb"].value<int64_t>())      _maxCorpusMb = (int)*v;
if (auto v = tbl["learning"]["min_sentence_chars"].value<int64_t>())  _minSentenceChars = (int)*v;
if (auto v = tbl["learning"]["include_examples_in_prompt"].value<bool>())
    _includeExamplesInPrompt = *v;
```

In `save()`, write to `[inference]`:

```cpp
infer.insert_or_assign("temperature", static_cast<double>(_temperature));
infer.insert_or_assign("top_p",       static_cast<double>(_topP));
toml::array stopArr;
for (const auto& s : _stopTokens)
    stopArr.push_back(s.toStdString());
infer.insert_or_assign("stop_tokens", std::move(stopArr));
```

In `save()`, write to `[learning]`:

```cpp
learn.insert_or_assign("max_corpus_mb",           _maxCorpusMb);
learn.insert_or_assign("min_sentence_chars",      _minSentenceChars);
learn.insert_or_assign("include_examples_in_prompt", _includeExamplesInPrompt);
```

## Step E5.2 — PageModel: Advanced inference section

**File:** `settings/qt6-app/qml/pages/PageModel.qml`

After the existing `XSection 02 Inference settings` (context window +
threads), add a collapsible `XSection 03 Advanced`:

```qml
// Collapsible advanced section — hidden by default.
property bool advancedExpanded: false

XSection {
    num: "03"
    title: "Advanced inference"
    // Chevron toggle
    Row {
        spacing: 8
        Text {
            text: advancedExpanded ? "▲ Collapse" : "▼ Expand"
            color: Theme.ink45
            font.pixelSize: 12
            MouseArea {
                anchors.fill: parent
                onClicked: advancedExpanded = !advancedExpanded
            }
        }
    }
}

Column {
    visible: advancedExpanded
    spacing: 0

    XRow {
        label: "Temperature"
        desc: "Controls randomness. Lower = more predictable completions. (0.0 – 1.0)"
        XSlider {
            min: 0.0
            max: 1.0
            stepSize: 0.05
            value: Config.temperature
            formatFn: function(v) { return v.toFixed(2) }
            onCommitted: function(v) { Config.temperature = v }
        }
    }

    XRow {
        label: "Top-P"
        desc: "Nucleus sampling cutoff. Lower = more focused. (0.0 – 1.0)"
        XSlider {
            min: 0.0
            max: 1.0
            stepSize: 0.05
            value: Config.topP
            formatFn: function(v) { return v.toFixed(2) }
            onCommitted: function(v) { Config.topP = v }
        }
    }

    XRow {
        label: "Stop tokens"
        desc: "Comma-separated list. Suggestion stops when any token appears."
        XInput {
            width: 280
            text: Config.stopTokens.join(", ")
            onEditingFinished: {
                var parts = text.split(",").map(function(s) { return s.trim() })
                                .filter(function(s) { return s.length > 0 })
                Config.stopTokens = parts
            }
        }
    }
}
```

**Note on XSlider with float step:** The existing XSlider primitive uses
integer steps in the current pages. Verify that XSlider supports `real`
min/max/stepSize — it should already handle this if implemented correctly
(Qt Quick Slider natively supports reals). If XSlider currently only
accepts integers, add `property real stepSize: 1` and use it in place of
any integer assumption.

**Note on stop_tokens UX:** A comma-separated text field is the simplest
approach. It is not as discoverable as a chip list, but avoids adding a
new primitive. The existing `\n` stop token must be displayed as `\n`
literally and re-parsed correctly:

```qml
text: Config.stopTokens.map(function(s) {
    return s.replace(/\n/g, "\\n")
}).join(", ")
onEditingFinished: {
    var parts = text.split(",")
        .map(function(s) { return s.trim().replace(/\\n/g, "\n") })
        .filter(function(s) { return s.length > 0 })
    Config.stopTokens = parts
}
```

## Step E5.3 — PagePersonalisation: Corpus settings section

**File:** `settings/qt6-app/qml/pages/PagePersonalisation.qml`

Add a new section after "Style learning" (section 01):

```qml
XSection {
    num: "02"
    title: "Corpus settings"
    description: "Control how much text is retained and how it is used"
}

XRow {
    label: "Max corpus size"
    desc: "Older entries are pruned when the file exceeds this limit."
    XSlider {
        min: 10
        max: 200
        stepSize: 10
        value: Config.maxCorpusMb
        formatFn: function(v) { return v + " MB" }
        onCommitted: function(v) { Config.maxCorpusMb = v }
    }
}

XRow {
    label: "Min sentence length"
    desc: "Shorter sentences are not added to the corpus."
    XSlider {
        min: 4
        max: 30
        stepSize: 2
        value: Config.minSentenceChars
        formatFn: function(v) { return v + " chars" }
        onCommitted: function(v) { Config.minSentenceChars = v }
    }
}

XRow {
    label: "Use corpus in prompt"
    desc: "Include writing style examples from your corpus in the AI prompt."
    XToggle {
        on: Config.includeExamplesInPrompt
        onToggled: function(v) { Config.includeExamplesInPrompt = v }
    }
}
```

Re-number the existing "Your voice profile" section to "03" and "Your
voice settings" (from E3) to "04".
